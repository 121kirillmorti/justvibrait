# JustVibrait Motor Monitor (Windows)

Настольный монитор для отладки вибрации Android-приложения **JustVibrait**.
Показывает, какие вибромоторы телефона получают команды, с какой амплитудой и
насколько вибрация реально доходит до корпуса (по акселерометру).

## Быстрый запуск

1. Подключите телефон и ПК к одной Wi-Fi сети.
2. Запустите `JustVibraitMotorMonitor.exe`.
3. В приложении на телефоне откройте **Настройки → Отладка → Монитор на ПК** и
   включите переключатель. Если ПК не находится автоматически, введите IP,
   который показан в окне монитора.
4. Если Windows блокирует UDP, один раз запустите `allow-firewall.ps1`
   (потребуются права администратора).
5. Нажмите **ДЕМО** в окне монитора, чтобы проверить интерфейс без телефона.

## Что показывается

- **ФАКТИЧЕСКАЯ ВИБРАЦИЯ** — оценка по акселерометру телефона в процентах и м/с².
- **КОМАНДА** — амплитуда, которую приложение отправило мотору (0–255), и её
  длительность. Показывается отдельной карточкой для каждого вибромотора,
  который перечислил Android (`VibratorManager` на Android 12+).
- **ТАЙМЛАЙН** — 15 секунд истории: факт (голубой) и команда (розовый).
- **СИГНАЛ** — бас, уровень, темп, порог и интенсивность в реальном времени.

## Важное ограничение

Android не отдаёт приложениям фактическую амплитуду, с которой сработал мотор.
Поэтому «КОМАНДА» — это то, что запросило приложение, а «ФАКТ» — независимая
оценка вибрации корпуса по акселерометру. На телефонах с несколькими моторами
карточки показывают команды по каждому id, но измерить каждый мотор отдельно
штатными средствами Android нельзя.

## Формат телеметрии (для отладки)

UDP-порт **45454**, одно таб-разделённое сообщение `JV1` на пакет:

```
JV1  seq  uptimeMs  device  android  sdk  source  profile  intensity  threshold
     bass  level  bpm  beat  measured  measuredMs2  hasSensor  defaultMotorId
     motors
```

`motors` — список `id:hasAmplitude:amplitude:durationMs:isDefault;...`.

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт использует `csc.exe` из .NET Framework 4.8 и складывает результат в
`dist/JustVibraitMotorMonitor.exe`. `--demo` запускает синтетический режим.
